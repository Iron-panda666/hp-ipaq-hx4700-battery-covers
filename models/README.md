# Local model inputs

Place the final STL files in these local folders:

- `models/Thin/`
- `models/Max/`
- `models/Shared/` — supplied Holder, Lever and Lever cover parts

STL inputs are ignored by Git. The distributable ZIP archives are stored in `releases/` and always include the full CC BY-NC 4.0 license and attribution.

The current model inputs are stored locally and are distributed in the combined ZIP archive. Do not substitute unrelated or placeholder STL files.
